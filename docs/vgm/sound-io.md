# VGM再生サンプル向け 音源ボードのI/O仕様と書き込み手順

## 目的

VGM再生サンプルのターゲットである2つの音源ボード(PC8001-YM2203、PC8001-PSG)について、I/Oポートとレジスタ書き込み手順を整理する。YM2203を先行ターゲットとする。

## YM2203ボード(PC8001-YM2203)

YM2203ボードはPC-8001の外部CPUバスに接続するFM音源ボードである。リポジトリは https://github.com/kuninet/PC8001-YM2203 に位置する。

### I/Oポート

YM2203ボードのI/Oポート配置は以下のとおりである。

| ポート | 機能 |
|---|---|
| 80H | レジスタ番号の書き込み、ステータスの読み出し |
| 81H | データの書き込み |

### レジスタ書き込み手順

YM2203へのレジスタ書き込みは以下の手順に従う。

1. 80HをINし、ステータスのビット7(BUSY)が0になるまで待つ
2. 80Hへレジスタ番号をOUTする
3. 短い待ちを入れる(既存サンプルVGM2203.asmではダミーのメモリ読み出し1命令)
4. 81Hへデータ値をOUTする

### VGMファイルでの表現

VGMファイル内でYM2203への書き込みはコマンド55H(続いてレジスタ番号、データ値の2バイト)で表される。

## PSGボード(PC8001-PSG)

PSGボードはGSX8800風のI/O配置を持つAY-3-8910を2個搭載するボードである。リポジトリは https://github.com/kuninet/PC8001-PSG に位置する。

### I/Oポート

PSGボードのI/Oポート配置は以下のとおりである。初期設定ではPSG#1が0A0H〜0A1H、PSG#2が0A2H〜0A3Hを占有する。ジャンパ設定により0A4H〜0A7Hへ変更できる。

| ポート | 機能 |
|---|---|
| 0A0H | PSG#1レジスタ番号 |
| 0A1H | PSG#1データ |
| 0A2H | PSG#2レジスタ番号 |
| 0A3H | PSG#2データ |

### レジスタ書き込み手順

PSGへのレジスタ書き込みは以下の手順に従う。

1. レジスタ番号ポートへレジスタ番号をOUTする
2. 続いてデータポートへデータ値をOUTする

BUSYフラグの確認は不要である。

### VGMファイルでの表現

VGMファイル内でAY-3-8910への書き込みはコマンド0A0H(続いてレジスタ番号、データ値の2バイト)で表される。

## SD-DOSの使用ポートとの衝突確認

SD-DOSが使用するI/Oポートは次のとおりであり、YM2203ボード(80H/81H)およびPSGボード(0A0H〜0A7H)のポートとは衝突しない。

| ポート | 用途 |
|---|---|
| 0FCH〜0FFH | 8255(SDドライブのビットバンギング制御) |
| 40H | 出力(本体システムポート) |
| 08H、09H | キーボード入力 |
| 0FDH、0FFH、0E2H | 64KB RAM版ローダの起動時のみ使用 |

## 初期方針

YM2203を先行ターゲットとし、VGM再生サンプルの音源書き込みルーチンはYM2203の書き込み手順に従う。PSG対応は後続で追加する。初期段階ではPSG#1(0A0H/0A1H)のみを対象とする。

## 今後の確認事項

* YM2203ボードのクロック周波数と、VGMヘッダに記録されたクロック値との対応
* レジスタ選択後の待ち時間の妥当性(既存サンプルのダミー読み1命令で足りるか)の実機確認
* PSG#2(0A2H/0A3H)を使うVGM(PSG2個構成)への対応要否
* ジャンパでI/Oアドレスを変更したPSGボードへの対応方法(サンプルの定数変更で対応するか)
