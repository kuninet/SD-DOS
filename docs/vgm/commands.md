# VGM再生サンプルのコマンド解釈範囲とタイミング制御

## 目的

VGM再生サンプルが初期実装で解釈するVGMコマンドの範囲、未対応コマンドの読み飛ばし規則、タイミング制御の方式を決める。

## 初期実装で解釈するコマンド

1サンプル=1/44100秒である。

| コマンド | オペランド | 動作 |
|---|---|---|
| 55H | レジスタ番号、データ値 | YM2203へ書き込む([音源ボードのI/O仕様](sound-io.md)の手順) |
| 0A0H | レジスタ番号、データ値 | PSG(AY-3-8910)へ書き込む(PSG対応版のみ。YM2203版では読み飛ばす) |
| 61H | サンプル数(2バイト、リトルエンディアン) | 指定サンプル数だけ待つ |
| 62H | なし | 735サンプル(1/60秒)待つ |
| 63H | なし | 882サンプル(1/50秒)待つ |
| 70H〜7FH | なし | (下位4ビット+1)サンプル待つ |
| 66H | なし | 再生を終了する |

## 未対応コマンドの読み飛ばし規則

未対応のコマンドは、VGM仕様のオペランド長に従って読み捨てて続行する。これにより他のチップ向けコマンドが混在するVGMでも再生を継続できる。

| コマンド | 読み捨てるバイト数 |
|---|---|
| 30H〜3FH | 1 |
| 4FH、50H | 1 |
| 51H〜5FH(55Hを除く) | 2 |
| 64H | 3 |
| 67H | データブロック。後続の66H、タイプ1バイト、サイズ4バイト(リトルエンディアン)を読み、サイズ分を読み捨てる |
| 80H〜8FH | 0(YM2612 DAC+ウェイト。出力はせずウェイトのみ下位4ビット分行うか、単に無視するかは実装時に決める) |
| 90H〜95H | 順に4、4、5、10、1、4 |
| 0A1H〜0AFH | 2 |
| 0B0H〜0BFH | 2 |
| 0C0H〜0DFH | 3 |
| 0E0H〜0FFH | 4 |

上記に該当しない未知のコマンドに当たった場合は、データ列の解釈が崩れているため、メッセージを表示して再生を停止する。

## タイミング制御の方式

初期実装はビジーループによる近似とする(PC8001-YM2203リポジトリの既存サンプルVGM2203.asmと同じ方式)。

サンプル数に比例する時間をループで消費する。1サンプル=約22.7マイクロ秒(Z80 4MHz換算で約91クロック)に対し、ループの定数で近似する。

ループ定数はソース内の定数として定義し、実機での聴感確認で調整できるようにする。

割り込みは使用しない。

### 精度の制約

次の制約を記録する。

- コマンドの読み出し・解釈・音源書き込みに掛かる時間はウェイトから差し引かれないため、テンポは理論値よりわずかに遅くなる
- 短いウェイト(70H〜7FH)は処理時間だけで消化されてしまう場合がある

## ストリーム読み出しの遅延との関係

ストリーム読み出しAPIの1バイト取得は、セクタ境界をまたぐ取得時にSD読み込みの遅延が集中する([ストリーム読み出しの取得単位とバッファ](../design/buffer-unit.md))。

初期実装ではこの遅延もウェイトと直列に発生するため、512バイトごとにテンポが一瞬遅れる可能性がある。

対策(ウェイト中の先読みなど)は初期実装では行わず、実機での聴感確認の結果で要否を判断する。

## 今後の確認事項

* ループ定数の実機での調整(テンポの聴感確認)
* セクタ境界の読み込み遅延が聴感上問題になるか
* 80H〜8FH(YM2612 DAC+ウェイト)のウェイト分を消化するかの実装判断
* ウェイト中の先読みなどテンポ安定化の要否
