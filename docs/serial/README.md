# シリアル受信サンプル(SDRECV)

`samples/SDRECV.asm` は、PC-8001 の外付け RS-232C ボード([kuninet/PC8001ext232C](https://github.com/kuninet/PC8001ext232C))Ch1 から、母艦(Mac/PC)が打った文字を **割り込み駆動で受信し、画面に表示+エコーで返す**サンプルである。後続の YMODEM 受信サンプル(`STRM_CREATE`/`STRM_WRITE`/`STRM_FCLOSE` 連携)を載せる前の **シリアル骨格** として用意した。

## 想定するハード

- 外付け 232C ボード: 8251 ×2
- Ch1: I/O ポート
  - `0C0H` = データ レジスタ(読み=受信、書き=送信)
  - `0C1H` = コマンド/ステータス レジスタ
- 受信割り込み:
  - モード 2 ベクタ `08H`(Ch1)/`0AH`(Ch2)→ CPU は `(I << 8) | 08H` = **`8008H`** に格納されたアドレスへジャンプ
  - 通常は N-BASIC ROM 内の標準シリアル処理アドレスが入っており、SDRECV はこれを**一時的に自前 ISR へ書き換え**、終了時に**元へ復元**する

## ボーレート

ボード側のボーレートジェネレータで **9600 8N1** を想定。8251 の初期化は ×16 クロック、8ビット、ストップ 1、パリティ無し。

## 使い方

### 母艦(Mac)側

```sh
brew install tio        # シリアル端末
# USB シリアル変換 + 232C ボード を 9600 8N1 で接続
tio -b 9600 -d 8 -s 1 -p none /dev/tty.usbserial-XXXX
```

### PC-8001 側

```
LOAD "SDRECV.CMT"
```

機械語モニタで **`G9000`** で起動(`CMD R` ではなくモニタの Go コマンド)。

```
-- SDRECV ECHO --
PRESS KEYS ON HOST. Q=END
```

の表示が出たら、母艦の `tio` でキーを打つと PC-8001 の画面に文字が出ると同時に**そのまま母艦へエコー返し**される。**`Q` または `q`** を入力すると `BYE` を表示して BASIC に戻る。

## 内部構成

| 部品 | 役割 |
|---|---|
| `INSTALL_ISR` | 8251 受信を一旦停止 → `8008H` のベクタを `SAVED_VEC` に退避 → 自前 `ISR` のアドレスを書き込み → 8251 をリセット → モード(`4EH`)→ コマンド(`15H` = RxE+TxEN+ER)で受信を有効化 |
| `UNINSTALL_ISR` | 8251 受信を `CMD_RXOFF` で停止 → `SAVED_VEC` を `8008H` に書き戻し |
| `ISR` | `0C1H` ステータス確認(エラーがあれば ER でクリア)→ `0C0H` から 1 バイト読み出し → リングバッファ末尾へ格納。満杯なら破棄し `RBUF_OVR` をインクリメント |
| `GETC` | リングが空ならビジー待ち、非空なら先頭バイトを取り出して `R` を進める |
| `PUTC` | `0C1H` の TxRDY を待って `0C0H` へ送信 |

リングバッファは `0A000H` から 256 バイト(8 ビットインデックスでラップ完結)。`RBUF_W` は ISR のみが更新し、`RBUF_R` は `GETC` のみが更新するため Z80 の単命令メモリ操作で完結する。

## 設計上のメモ

- **ベクタ復元は必ず行う**。終了時に復元しないと、ISR の物理アドレスが上書きされた状態で BASIC のシリアル処理がそのまま呼ばれ続けて暴走する
- **8251 のモード/コマンド値**(`4EH` / `15H`)は理論値。実機で N-BASIC が `OPEN "COM:"` 時にどんな値を書いているかを確認して必要なら調整する
- **ボーレート**はボード側で決まるため、ソフトは値を意識しない。9600 を超える設定で受信がもたつく場合は割り込み禁止区間(`DI`)が長すぎる可能性がある
- **9600 8N1**: 1 文字 ≈ 1.04 ms。PC-8001 の実効 1.84 MHz でも ISR の数十命令は十分間に合うが、画面表示(RST 18H)が長引くと取りこぼし得るので、**画面表示はメインループ側**、ISR は**リング格納のみ**にしている

## テスト

- リングバッファの動作(`GETC` の取り出し・インデックス進行・ラップ・W==R 空判定)は `scripts/test_sdrecv.py` でエミュ検証(`make test`)
- 8251 I/O と割り込み(`ISR`/`RETI`)は z80mini に I/O ポート/割り込みモデルが無いため **実機検証**

## 次にやること

- YMODEM 受信ステートマシン(SOH/STX ブロック、CRC-16、ACK/NAK、ブロック 0 のファイル名/サイズ解釈、EOT)を載せる
- 受信ペイロードを `STRM_WRITE`(6017H)で SD に書き、`STRM_FCLOSE`(601AH)で確定する
- 母艦は `lrzsz` の `sb -k file.vgm`(YMODEM 1K)を実行するだけで転送できる構成にする
